# Watchpost - mapping of domains to publishers (Tracking page, contract §9).
# Version 1 (2026-11-16). Versioned with the collector and embedded in the binary.
#
# Format:
#   [key] Display name    opens a publisher (key: [a-z0-9_]+, in display order);
#   domain.suffix         each following line attaches this domain AND its subdomains to that publisher;
#   # ...                 comment (whole line).
# The longest suffix wins (a subdomain listed elsewhere takes precedence over its parent), on label
# boundaries: "google.com" covers "www.google.com" but not "notgoogle.com".
# A domain that matches nothing is attached to "other". A suffix can appear only once.
# Attachment rule: the company that operates the domain (DoubleClick and AdMob are Google);
# "ads" groups the advertising networks and audience measurement tools of the other companies.
